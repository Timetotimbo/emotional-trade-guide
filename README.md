# Trading Psychology Atlas

An interactive atlas of the emotional triggers, psychological responses, and market events that shape every trader's decisions.

**Live site:** https://timetotimbo.github.io/emotional-trade-guide/

## Run locally

Requires Node.js 18+.

```sh
npm install
npm run dev
```

Then open http://localhost:8080/.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages via `.github/workflows/deploy.yml`.

## Tech

Vite, React, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion.
